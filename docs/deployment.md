# Deployment

## Pre-Deployment

- Run the release checklist: `docs/pre-deployment-checklist.md`

## Vercel

- Automatic deployment from GitHub main branch
- Environment variables set in Vercel dashboard
- Build command: `npm run build`
- Output: `.next/`

## Local

- `npm install`
- `npm run build`
- `npm start` or `npm run dev`
